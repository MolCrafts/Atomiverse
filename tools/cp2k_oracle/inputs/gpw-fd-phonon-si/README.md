# Si2 GPW vibrational reference

`reference.json` freezes actual CP2K 2026.2 (`git:c92cc08`) output from
2026-10-25 for the three `si2_matched_*.inp` inputs. All three jobs exited
zero. The complete successful outputs are the neighboring `.cp2k.txt`
files, including the vibration force trace. Input/output/data hashes,
commands, version, environment and process walls are recorded. These are
`CORE_PPL GRID` calculations, matching native `local_pp_on_grid=true`.

In a fresh directory with the three inputs copied there, run in order:

```sh
export OMP_NUM_THREADS=8 OPENBLAS_NUM_THREADS=1
export CP2K_DATA_DIR=/opt/homebrew/share/cp2k/data
unset OMP_PROC_BIND OMP_PLACES
cp2k.psmp -i si2_matched_energy_force.inp -o si2_matched_energy_force.out
cp2k.psmp -i si2_matched_geo_opt.inp -o si2_matched_geo_opt.out
cp2k.psmp -i si2_matched_vib.inp -o si2_matched_vib.out
```

The first calculation supplies the nonstationary 2.246 Angstrom energy and
full force vector. Geometry optimization generates
`si2_matched_geo_opt-RESTART.wfn`; the vibration input explicitly reuses that
file to follow the same converged electronic branch. The restart is
regenerated by this sequence; its actual SHA256 is recorded.

The vibration **input** has bond 2.1450905162 Angstrom. The final GRID
optimization has bond 2.1450907568000073 Angstrom and tiny transverse shifts;
its complete coordinates are in `si2_matched_geo_opt-final.xyz`. The bond
difference is -2.4060000747e-7 Angstrom. The regression uses the actual
vibration input unchanged, rather than substituting the nearby optimized
coordinates beneath an existing frequency pin.

In `si2_matched_vib-r-0.cp2k.txt`, the first 12 force evaluations are the
plus/minus Cartesian displacements. The **last, thirteenth evaluation**
restores the undisplaced vibration input: line 2202 prints energy
-7.603345177586478 Ha; lines 2206–2207 print forces with largest absolute
component 7.09733727e-8 Ha/Bohr (largest norm 7.11897870e-8 Ha/Bohr).
This independently verifies stationarity under the unchanged 1e-5 Ha/Bohr
regression bound. The main vibration output line 568 prints the stretch
573.65790135 cm^-1 after removal of rotations and translations. Native
Phonon returns unprojected Cartesian modes; the five near-zero modes retain
their separate physical-symmetry bound.

Process walls at one MPI rank, with environment requests
`OMP_NUM_THREADS=8` / `OPENBLAS_NUM_THREADS=1`, binding unset:
energy/force 70.622467s, optimization 118.210183s, vibration 133.218425s.
The actual CP2K internal BLAS width was not queried; the environment request
does not establish single-thread BLAS for an OpenMP OpenBLAS build. No fair
matched-width wall ratio is claimed from these records.
The native section includes its energy/force preflight and energy-curvature
checks in addition to the phonon calculation, so its complete-section wall
must be distinguished from the external vibration-only boundary. All original
energy, force, stationarity, frequency and 60s section bounds are retained.
ctest never launches CP2K.
