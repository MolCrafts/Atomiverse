# Atomiverse 高分子 MC / kMC 开发计划

先交付可验证的全原子高分子构象采样，再用独立 MD 数据建立带物理时钟的离子迁移模型，最后验证链运动与离子输运的耦合。首个 MC 交付限定在 CPU 单 rank、固定化学连接的 NVT 体系。研究验收使用 METAC、MTFSI、PEGM 共聚物及其盐体系，功能正确性先在小体系上建立。

## 当前开发起点

原始基线为 `dev` 的 `9e6805ed4`。重构后的 CPU `MC` 直接继承 `Driver<sampling::Phase>`，由 `set_nvt`、`set_npt` 或 `set_gcmc` 安装平衡系综策略。`KMC : public MC` 作为独立 driver 继承运行生命周期，并通过 `set_event` 和 `set_solver` 显式装配事件及抽样算法。`Mover` 和 `MoveSelector` 生成试探，`Transaction` 保存被修改的原子行及盒子，`OutcomePolicy` 判定接受或拒绝。普通拒绝路径回滚后会重新计分。当前 NVT 位移接受规则只使用能量差，现有 `TranslateMove` 以单原子为移动对象。首批工作是在这些接口上扩展概率信息、分子选择和多原子状态更新，并用下一次计分验证回滚和缓存的一致性。[MC 循环](../../src/cpu/montecarlo/mc.cpp) · [接受策略](../../include/atomiverse/cpu/driver/outcome_policy.h) · [事务](../../include/atomiverse/cpu/montecarlo/transaction.h)

## 扩展接口与复用边界

| 层次 | MD | 平衡 MC | 连续时间 kMC |
| --- | --- | --- | --- |
| 用户配置的组件 | `set_integrator(Integrator)` | `set_mover(Mover)`，用 `MoveSelector` 混合多个 move | `set_event(Event)` 提供跃迁，`set_solver(KineticSolver)` 按速率抽样 |
| 一次状态推进 | `Integrator` 在 MD 各阶段使用 evaluator 提供的力，推进坐标和速度。MD 的物理时间由步数和时间步长确定 | `Mover` 生成候选，evaluator 计分，`OutcomePolicy` 判定，`MC` 提交或恢复。合起来定义一次 Markov 转移 | 当前模型给出事件及速率，调度器抽样事件与等待时间，模型应用该事件 |
| 观测所用时标 | MD 物理时间 | 试探次数，包含拒绝时的原状态 | kMC 模型的物理时间，状态统计按驻留时间加权 |

- **新增 `Mover` 的路径。** 现有 C++ `set_mover` 和 `MoveSelector::add` 已按组件接收 mover。一个沿用已支持概率测度和状态变更类别的 mover，应只实现自身适用条件、分子几何和 proposal 概率，并通过已有计分与事务服务运行。`MC` 按通用协议推进，`OutcomePolicy` 按系综和 proposal 数据判定，统计按所选组件识别新 move。`Verb` 继续表示位移、体积、插删等状态变更类别。PR 2 用在独立 C++ 调用方定义的 mover，验收直接安装和混合选择两条路径，验证核心 driver、接受策略和枚举都可以原样使用。
- **Python 扩展面。** 当前 `.set_mover()` 与 `MoveSelector.add()` 分别枚举内置类型。PR 2 将两处接入集中到同一套原生 mover 绑定约定，使新增 C++ mover 时只需声明其 Python 类型和参数。用同一个新 mover 验证两条入口、组件所有权和运行期寿命。Python 用户继续从 `molpy.Frame` 配置体系和组合已绑定的组件。[当前 Python 绑定](../../python/src/bindings/bind_mc.cpp)
- **复用 MD 的基础设施。** 同一 backend 上复用 `Frame`、原子标识、拓扑、盒子、evaluator 和邻居表实现。各 driver 负责自己的阶段与缓存刷新时机。MC 每次候选计分前执行所需的邻居检查，拒绝后按事务规则恢复或重建。工作流经 `Frame` 快照串联，轨迹记录和分析按各自时标解释。[MD 执行模型](../../docs/developer/md-execution-model.md)
- **kMC 接口。** `set_event(Event)` 和 `set_solver(KineticSolver)` 显式装配可替换组件。Python 的 `run(frame, n_events)` 以执行事件数为预算，速率和时钟固定用 ps⁻¹ 和 ps。每个已提交事件发布稳定 ID、等待时间，以及可选的跨周期展开位移。观察每个事件即可保留历史。当前 solver 契约每步枚举、验证并扫描全部速率。增量事件表与树更新需要独立接口和实测依据。
- **kMC 的扩展点。** `KMC` 继承 `MC` 的 `run`、随机数、事务、运行结束判据和步末观测。事件和速率模型拥有可行事件及其状态更新，调度器拥有事件和等待时间的抽样。kMC 在物理意义相同的地方复用几何、周期映像、随机数和输出基础设施。事件若写入原子构象，可复用确定性的几何更新及所需的 evaluator。离散配位模型可以直接推进盆地状态，事件位移从模型规则得到。`MC` 的 proposal、接受判定和拒绝回滚属于平衡 MC。用有已知解且包含跨周期位移的小模型验证调度器，再将同一事件抽样和计时实现接到 Li 迁移模型。[SPPARKS 调度器接口](https://spparks.github.io/doc/solve_style.html)

## PR 1 · 概率、试探状态与候选计分

- **接受规则。** `OutcomePolicy` 在对数域组合目标分布比与 proposal 的反向／正向概率比，统一约定坐标测度。逐项追溯移动类型、链、片段和几何解的选择概率。固定对称权重可约去，随状态变化的资格筛选和重抽样须纳入推导。Rosenbluth 权重按 CBMC 的提议推导计入，Jacobian 按测度计入一次。空候选和反向概率为零都记为拒绝。实际选中的 move 为每次非空试探提供概率修正。现有 NVT、NPT 和 μVT 接受策略都会读取显式提议修正。NPT 体积与 μVT 插删的修正相对于各自参考试探，未声明修正的非空试探报错。侧链多候选计分与复杂复合试探仍从 NVT 开始验证。[Cassandra 接受规则](https://cassandra-mc.readthedocs.io/en/stable/theory/theory.html)
- **外层事务。** 每次试探都从上一个已接受构象开始，`Transaction` 对同一原子行和盒子保留第一次修改前的值。`MC` 管理提议、计分、判定、提交或恢复、观测的顺序。候选无解是正常拒绝，恢复后沿用原状态作为该次试探的观测结果。计分异常在恢复后上报，以恢复完整的已接受状态作为继续运行的前提。验收覆盖重复改写同一行后拒绝、几何失败前已有部分写入，以及 evaluator 写入部分输出后抛错。恢复后核对坐标、周期映像、盒子及可见输出。给定同一个后继候选，所得能量差应与未经历失败试探的对照一致。派生缓存可失效重建，evaluator 历史的提交或丢弃沿用现有 runtime 机制可支持的边界。[Frame 事务](../../src/cpu/montecarlo/transaction.cpp) · [Evaluator 历史](../../include/atomiverse/core/evaluation_history.h)
- **候选计分。** 在冻结接口前，用含一条已标注 PEGM 侧链的小体系，验证单个二面角的最小正反向多候选流程。由 `MC` 调用已配置的 evaluator，复用能量和邻居更新路径。每个候选从本次生长阶段约定的构象出发，恢复或切换候选时保留外层事务的原始快照。候选分数只参与构造 proposal，最终构象按同一 Hamiltonian 做全体系计分，由 `OutcomePolicy` 判定一次。候选阶段的 evaluator 输出和历史要么隔离，要么在下一次计分前恢复。只有最终接受的构象可以更新已接受能量和历史。用带电周期小体系核对键合项、排除项、1–4 和长程静电。可从已有 GAFF–PEO 对照复用力场和周期条件，构建带盐算例。增量能量排在正确性与性能测量之后，届时保留全量核对路径。[GAFF–PEO 基准](../../benchmarks/compare/gaff-peo-lammps/README.md)

## PR 2 · 分子几何、选择与诊断

- **选择与几何。** 分子连通分量和候选轴键切开后的随动分支由 `Frame` 键图与原子标识推导。主链／侧链角色、锚点、固定原子或交联限制等无法可靠推断的选择，由 `Frame` 中显式输入的角色或标记表达。PR 2 在原生与 Python 端约定最小必需字段，验证读回的原子和键选择一致。配置要求的字段缺失、格式错误或约束类型不受支持时，在运行前报出具体原因。合法配置下抽中的片段若几何不可用，则记为该 move 的一次拒绝。
- **移动及不变量。** 离子平移选择单原子离子。整分子平移与转动对当前构象施加同一次刚体变换，也适用于柔性分子。二面角优先做 PEGM 侧链，再推广到主链。沿键图重建跨周期的连续几何，移动后复用现有盒子几何更新坐标与周期映像。每种 move 随 PR 提交简短推导和适用条件，核对序列、链长、支化、原子类型、电荷、立体化学、环结构和约束。若研究限定缠结或结拓扑，另行验证移动是否维持该限制。复合移动的接受推导覆盖完整生成路径，包括任何松弛步骤。[原子拓扑与 MolPy 边界](../../docs/developer/frame-architecture.md) · [验证约定](../../docs/developer/project-contract.md)
- **统计与采样。** 在选中具体 move 时记录其身份，最终判定后记录尝试、接受、拒绝原因和计分耗时。离子平移、分子转动和二面角各自可查，同时保留已有按 `Verb` 的统计入口。一次 CBMC 的多个内部候选计入该次 move 的计分开销。首版 Python 示例用同一 MC 实例分段调用 `run()`，以固定试探间隔记录构象，包含拒绝时的原状态，并核对连续运行和分段运行得到相同的试探序列。长链采样和外部参考对照走现有科学 benchmark，局部函数检查进入单元测试。[科学 benchmark](../../docs/developer/scientific-benchmarks.md)

## PR 3–5 · 从局部构象到可用的 MD 初态

- **侧链 CBMC。** 将 PR 1 的单二面角多候选流程扩展为固定锚点的末端子树逐段重生长。按推导将旧构象纳入逆向候选集，说明各步候选的引导能量、最终接受修正与全候选无效时的恢复。先在短链上用可枚举参考验证正反向权重，再扩展到链端。采用和 PR 2 相同的势能、盒子及墙钟预算比较。
- **ConRot。** 先限定固定连接和端点闭合的明确链段模板。独立验证数值闭合、可逆解的枚举与加权、Jacobian、近奇异解处理和随动支链的不变量。以主链二面角、端到端构象和第一 Rouse 模态的相关性衡量收益。若收益主要出现在局部，报告对应空间尺度。
- **采样验收。** 首批小体系用可枚举或可积分分布，并比较不同 move 组合所得的平衡统计。研究示范建议挑选一个已有完整力场与参考轨迹的共聚物组成，固定温度、盐比和序列，使用多个独立制备初态与种子。报告侧链二面角、Li–PEGM/Li–TFSI 等配位、主链构象及慢模态的相关性与 ESS/墙钟时间。对仍未充分去相关的量报告观测窗与初态间差异。扩展到不同组成和序列时复用同一验收协议。[Mavrantzas 2021，聚合物移动与构象偏置](https://doi.org/10.3389/fphy.2021.661367)
- **MC → MD。** 用现有 Python MC 和 MD 入口组合工作流。将 `molpy.Frame` 的独立快照交给 MD，核对拓扑、盒子、坐标和周期映像。记录力场、温度、种子、移动配置、MC 取样位置及初态制备方式。进入 MD 时按热化协议设置速度，局部再平衡后启动独立物理时间轴。规范初态和基准的产物包括能量、局部配位、慢模态和构象间差异，以及 MD production 的扩散、电导率和链动力学 ACF。保留既有 MD 制备路线作为对照，并报告跨初态的差异和误差。

## PR 6 · Li 迁移模型与物理时间验证

1. **提前审查 MD 数据。** 从已有参考 MD 核对采样间隔、可追踪的 Li 和配位对象标识、周期盒及展开位移，并按独立轨迹或独立制备构象划分拟合与留出数据。用拟合数据试标记配位盆地、链内迁移、链间转移及配位交换。核对各类跃迁的事件数、有效驻留时间、短时回穿及标签对采样间隔的敏感性。比较同一状态在不同进入路径、驻留年龄下的后续行为。用候选事件位移重建 Li 的跨周期位移，并与原始 MD 比较，检查配位变化和空间移动各自遗漏了哪些位移。
2. **锁定首版模型。** 首版为连续时间 Markov 模型，速率只依赖当前模型状态，在两次事件之间恒定。固定链背景可作为对照。根据事件计数和在险驻留时间估计速率与不确定度，再确定事件的位移及周期更新规则。状态、速率、位移规则和验收误差标准在使用留出数据前确定。若筛查显示跃迁样本不足、驻留统计仍有明显历史依赖或位移重建偏差明显，先补数据或改状态划分，物理时间的交付以通过复核为条件。
3. **调度与物理验收。** 模型拥有事件列表、速率和状态更新规则，调度器拥有事件抽样及物理时钟。调度器从当前总速率抽样等待时间，按各事件速率选出下一事件，应用事件后全量重建列表。用有已知解的系统验证事件比例、等待时间、驻留时间加权和零总速率的停止行为。单独用留出 MD 验证状态占据、驻留时间、跃迁分支、Li MSD 曲线和自扩散系数，报告对照误差与统计不确定度。以全量重算结果作为之后验证局部事件更新的对照。[SPPARKS kMC 算法](https://spparks.github.io/tutorial/html/kmc_algorithm.html) · [SPPARKS 事件选择](https://spparks.github.io/doc/solve_style.html)

## 后续扩展的启动条件

- **链运动耦合。** 将链构象及其跃迁纳入联合状态。若采用随连续链背景变化的速率，则为它另定义并验证依赖时间的事件抽样规则。用独立 MD 验证链段与主链 ACF，并比较固定链背景与动态链模型的离子输运，检验耦合是否改变目标预测。
- **集体输运。** Li 自扩散通过验证后，加入携带电荷的多离子状态、跨周期集体位移和离子交叉关联。将集体电荷位移和交叉项与留出 MD 对照，通过后再报告模型电导率。

局部采样通过验收后，若慢模态仍受势垒限制，评估把 MC 接入现有副本基础设施。`dev` 已有 T-REMD 和 H-REMD，任何 MC 接入都需验证副本内核与交换后分布。Pivot、reptation 和 bridging 按密度、序列与拓扑适用性分别评审。允许重连的算法应先定义目标系综、可保持的分子不变量和对应接受概率。[现有采样路线图](../../docs/roadmap/sampling.md)
