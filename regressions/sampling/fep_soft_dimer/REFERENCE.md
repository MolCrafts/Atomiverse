# Reference — Kirkwood TI on soft LJ dimer

Fixed-geometry soft-core LJ dimer:

\[
\Delta U = \int_0^1 \frac{\partial U}{\partial\lambda}\,d\lambda = U(1)-U(0).
\]

- Kirkwood, *J. Chem. Phys.* **3**, 300 (1935)
- Soft map: Beutler et al., *Chem. Phys. Lett.* **222**, 529 (1994)

Parameters: ε=0.5 eV, σ=3 Å, r=3 Å, r_c=8 Å, α=0.5, p=1. Trapezoid N=40.
