## Summary

The wave-2 E7 foothold (`thomas-fermi-electrode`) hard-codes one global site
number density \(d\) in the Thomas–Fermi (TF) electrode hardness. MetalWalls
instead takes the **Voronoi volume of the electrode site** as a per-species
input (`voronoi_volume` next to `thomas_fermi_length`). This slug lands the
companion in two pieces: `cpu::VoronoiVolume` computes periodic Voronoi cell
volumes from geometry (typically once, on a bulk electrode crystal frame),
and `cpu::md::ConstPotBO` accepts per-site volumes through the public member
`site_volume`, applying \(A_{ii}\mathrel{+}= 4\pi k_e\,
l_{\mathrm{TF}}^2/v_i\). `ConstPotBO` stays a **Component** on `cpu::md::MD`
at `md::Phase::pre_force` — no new Driver category, no Config bag, no charge
solve inside `KSpace*`. The regression pins the tessellation on bulk FCC gold
(every \(v_i = a_0^3/4\) exactly) and the induced charge of the gold
capacitor toy against the MetalWalls-model pins.

## Method

**Physics.** Scalfi, Dufils, Reeves, Rotenberg, Salanne, *J. Chem. Phys.*
**153**, 174704 (2020), DOI
[10.1063/5.0028232](https://doi.org/10.1063/5.0028232): the semiclassical TF
metallicity self-energy is **per-site**,

\[
U_{\mathrm{TF}} = \sum_i \frac{l_{\mathrm{TF}}^2}{2\,\epsilon_0\,v_i}\,q_i^2
\quad\Rightarrow\quad
A_{ii}\;\mathrel{+}=\; 4\pi\,k_e\,\frac{l_{\mathrm{TF}}^{2}}{v_i},
\]

with \(v_i\) the Voronoi volume of electrode atom \(i\) in the electrode
crystal (metal units \(e\), Å, eV; \(k_e =\) `units::coulomb`
\(= 14.399645\) eV·Å/e²). The fixed-density foothold is the special case
\(v_i = 1/d\); for FCC gold \(v = a_0^3/4\) **exactly** (4 sites tile the
conventional cube; the FCC Voronoi cell is the rhombic dodecahedron).
Smaller \(v_i\) hardens the diagonal, reduces the induced charge at fixed
\(\Delta\Psi\), and lowers the integral capacitance
\(C = |Q|/|\Delta\Psi|\); perfect metal (\(l_{\mathrm{TF}} = 0\)) ignores
the volumes entirely.

**Tessellation.** `cpu::VoronoiVolume` computes cells by convex bisector
clipping: the initial cell is the box cuboid centred on the site (the
self-image bisectors of an orthorhombic lattice), clipped by the
perpendicular-bisector half-spaces of every neighbor image that can reach
the cell, nearest first with early termination. The tessellation is
generated by **all** atoms in the frame (min-imaged), so
\(\sum_i v_i = V_{\mathrm{box}}\) exactly by construction. Orthorhombic
boxes only; throws on triclinic, empty frames, and coincident sites. It is
a **setup-time companion** — a plain domain type, not a hot-path Component
(MetalWalls likewise treats `voronoi_volume` as a static input).

**Why MetalWalls (not LAMMPS):** LAMMPS ELECTRODE implements
perfect-conductor constant-potential electrodes only; finite TF metallicity
and its Voronoi-volume input are MW-only in this loop's oracle priority →
bind to MetalWalls / Scalfi, not LAMMPS.

### System

1. **Bulk FCC Au**, 2×2×2 conventional cells (32 sites), \(a_0 = 4.07\) Å,
   cubic box \(2a_0\), fully periodic — input to `cpu::VoronoiVolume`.
2. **Gold capacitor toy** — identical to
   `regressions/md/thomas-fermi-electrode`: 3+3 electrode planes
   (1 site/plane, types 1/2), \(L_x = L_y = a_0\), plane spacing \(a_0/2\),
   first-plane gap 20 Å, \(\Delta\Psi = 1\) V, Gaussian
   \(\eta = 1/0.56\) Å⁻¹ (MetalWalls \(w = 0.56\) Å), 2D \(xy\) image
   half-range 40, electroneutrality on, \(l_{\mathrm{TF}} = 2\) Å,
   box \(L_z = 80\) Å, empty vacuum (no electrolyte).

### Key exclusions (non-goals of this slug)

- Live MetalWalls or LAMMPS inside ctest (offline pin only).
- Triclinic cells and radical/weighted (Laguerre) tessellations.
- Per-step Voronoi recomputation on the MD hot path — static setup input,
  as in MetalWalls.
- Full electrode Ewald / MW reciprocal matrix (v1 2D-image \(A\)).
- Electrolyte / IL between the walls (empty capacitor toy).
- Public `*Config` bags or `make_*` / `build_*` factories.

## Implementation

Public surface only (`cpu::Frame` + `VoronoiVolume` + `ConstPotBO` members;
no Config bag). Minimal call sequence matching the regression:

```cpp
#include "atomiverse/cpu/dynamics/const_pot_bo.h"
#include "atomiverse/cpu/frame/frame.h"
#include "atomiverse/cpu/observe/voronoi_volume.h"

// 1. Site volumes from the bulk electrode crystal (MetalWalls workflow):
//    bulk FCC Au 2x2x2, a0 = 4.07 Å, box = cubic(2*a0).
cpu::VoronoiVolume vv;
std::vector<double> v = vv.volumes(bulk_gold);   // [Å³] per row; each = a0³/4

// 2. Feed the TF hardness per site (indexed by the run frame's rows).
cpu::md::ConstPotBO conp(/*eta [1/Å]=*/1.0 / 0.56);
conp.add_electrode(/*type=*/1, /*Psi [V]=*/0.0);
conp.add_electrode(/*type=*/2, /*Psi [V]=*/1.0);
conp.electroneutrality = true;
conp.xy_image_range = 40;
conp.l_tf = 2.0;                                  // [Å]; 0 = perfect metal
conp.site_volume.assign(frame_rows, v[0]);        // per-row v_i [Å³]

// Bound on the MD driver (defaults to pre_force order −50):
cpu::md::MD sim;
// ... neighbor / coulomb / integrator as needed ...
sim.add_ref(conp);   // or add(std::move(conp)) to own
sim.build();
sim.run(frame, /*nsteps=*/1);

double q_top = conp.total_charge(1);              // [e]
double c = conp.capacitance();                    // [e/V]
```

Exactly one of `site_density` / `site_volume` may be set when `l_tf > 0`
(throws otherwise); non-electrode rows of `site_volume` are ignored.
Solved charges land on `kAtom_charge` — Frame stays the sole I/O currency.

## Limitations

- **Orthorhombic boxes only.** `VoronoiVolume::volumes` throws on
  triclinic and degenerate boxes; also throws on coincident sites
  (separation < 1e−6 Å).
- **Setup-time companion, not a hot-path Component.** Volumes are computed
  once from the bulk crystal and stay static during MD — mirroring
  MetalWalls' static `voronoi_volume` input. No per-step re-tessellation.
- **Plain Voronoi only** — no radical (Laguerre) weighting for
  multi-species electrodes with unequal radii.
- **Discrete 1-site/plane capacitor toy** for the charge gates —
  under-samples lateral Au density vs continuum formulas (see the wave-2
  E7 page); the product gate is the discrete pin.
- **v1 elastance only.** Real-space Gaussian + 2D \(xy\) images; no full
  electrode Ewald / MW reciprocal matrix; empty vacuum (no electrolyte).
- **No fair speed ratio** until MetalWalls is on the pin host.
