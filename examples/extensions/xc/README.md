# An external CPU XC functional

This is a separate C++20 project. `ScaledSlater` implements a mathematical
`ATV::electronic::XcFunctional`; the existing RKS/UKS SCF Driver, grid engine
and analytic nuclear force path consume it. The provider has no Driver,
Context, geometry, basis state or iteration history. No Atomiverse enum entry
is added for this example.

Build/install Atomiverse with `ATV_BUILD_HF=ON`, `ATV_BUILD_EVALUATE=ON`,
`ATV_BUILD_CUDA=OFF` and an install prefix, then copy this directory outside
the checkout and run:

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/install
cmake --build build
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 ./build/xc-extension water
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 ./build/xc-extension h2plus
```

The only Atomiverse target is `Atomiverse::atomiverse`; dependencies and
compile definitions arrive through its installed CMake package. BLAS/LAPACK
and OpenMP (when enabled in the library) must be available to the consumer.
A nonstandard BLAS installation can be added to `CMAKE_PREFIX_PATH`.

The provider is held by `shared_ptr<const XcFunctional>` and may be shared
between independent methods. Input and output spans are call-scoped and must
never be retained. `evaluate` checks shapes, finite inputs and every requested
output; override `evaluate_batch`. `energy_density` is **energy per volume**
(Ha/Bohr³), `vrho` is its derivative in Ha; it is not an energy per electron.
Both spin densities are present, including in the restricted case.
`Sigma` uses (aa, ab, bb), where ab has no factor two. A GGA must write all
three derivatives, including explicit zeros when appropriate. Implement
`supports` honestly and reject requests that cannot be evaluated.

This slice supports molecular CPU RKS/UKS semi-local rho/sigma functionals,
energies, first derivatives and analytic nuclear forces. Tau/Laplacian,
second derivative kernels, external exact exchange/range separation,
ROKS injection, PW/GPW and CUDA execution are not provided by this example.
Unsupported ingredients are rejected at method construction, incomplete
outputs at evaluation, and custom response kernels before response solves.

## Independent acceptance pins

The two pins were generated by **PySCF 2.14.0**, installed in an isolated
Python 3.13 environment. Actual raw output is archived at
`tools/pyscf_oracle/inputs/xc-extension/{water,h2plus}.json`.
The reproduction commands, run from the Atomiverse checkout, are:

```sh
python tools/pyscf_oracle/pin_scf.py rks --geom water --basis sto-3g --xc '0.8*LDA_X,' --grad
python tools/pyscf_oracle/pin_scf.py uks --geom h2-1A --basis sto-3g --charge 1 --spin 1 --xc '0.8*LDA_X,' --grad
```

Cartesian STO-3G, PySCF grid level 3, SCF tolerance 1e-12 Ha; coordinates
in Å. Water: O(0,0,0.1173), H(0,0.7572,-0.4692), H(0,-0.7572,-0.4692).
H₂⁺: H(0,0,0), H(0,0,1), Nα=1, Nβ=0. Energies are
-72.4239632859654 and -0.48893340293176235 Ha. `pins.h` records every gradient
component verbatim from those outputs; force = minus gradient, converted to
eV/Å by Atomiverse's units constant.

Acceptance checks the energy and preservation of unrequested forces for
standalone `run` (an energy request), every energy/force component for
`forces`, and nesting the **same method instance** in `cpu::Evaluate`.
It also checks energy-only Frame preservation, unsupported-request failure and
retry, geometry/cell refresh, shared-provider isolation, and short MD/Minimize
composition when those domains are enabled. The moving-geometry checks exercise
lifecycle behavior; their numerical science qualification comes from the
corresponding existing method regressions. The RKS regression additionally
injects a callback failure and pins the successful same-object retry.
Tolerances fixed before the Atomiverse run: 1e-6 Ha energy and 2e-5 Ha/Bohr
force. The latter allows the independently known molecular Becke-grid
response difference between MatchPySCF and PySCF level 3 (the integration
grids have slightly different pruning), while catching sign/spin factors.
Nonfinite values fail. CTest pins are sections of `scf/rks` and `scf/uks`,
not new method cases.
